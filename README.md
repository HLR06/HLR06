## 🏦 Current Project: DousPAY

DousPAY is a financial super-app that lets you:

| Feature | Description |
|---------|-------------|
| 💸 **Send Money** | Instant transfers to Haiti and worldwide |
| 💱 **Exchange** | USD ↔ HTG ↔ USDT ↔ BTC in real-time |
| 💳 **Virtual Cards** | Free Visa & Mastercard cards |
| 📱 **Top-up** | MonCash, NATcash, Unibank, BNC, Sogebank |
| 🔒 **Security** | 2FA, Biometrics, Cold wallet (95% offline) |

**Tech Stack:** Next.js, React Native, Node.js, PostgreSQL, Redis, Docker, Kubernetes
